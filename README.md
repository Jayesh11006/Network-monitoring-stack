# Network Monitoring Stack

A lightweight DevOps + Network Monitoring project built using:

- Python Flask
- Docker
- Prometheus
- Grafana

## Features

- CPU Monitoring
- RAM Monitoring
- Disk Monitoring
- Ping Monitoring
- Port Checking
- Prometheus Metrics
- Grafana Dashboard

## Tech Stack

- Python
- Docker
- Prometheus
- Grafana
- Linux (WSL Ubuntu)
